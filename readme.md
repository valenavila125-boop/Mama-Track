# Mamá Track 🤱

Aplicación web para acompañar el trabajo de parto en tiempo real.

## ¿Por qué existe?

La construí mientras esperaba el nacimiento de mi hija Seressa. 
Necesitábamos una herramienta simple para registrar contracciones 
y saber cuándo ir al hospital.

## Funcionalidades

- ⏱️ Cronómetro de contracciones con inicio y fin
- 📊 Cálculo automático de duración e intervalo entre contracciones
- 😣 Registro de intensidad del dolor (escala 1-10)
- 👶 Seguimiento de movimientos del bebé con posición
- 💧 Registro de rotura de bolsa
- 📋 Historial completo de la sesión
- 🔒 Opción de mantener sesión activa

## Tecnologías

- HTML
- CSS
- JavaScript
